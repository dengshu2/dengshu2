## Data tools

**[SQLForge](https://github.com/dengshu2/sqlforge)** — Format SQL and convert it between 27 dialects, with syntax tree, column lineage and diff. Powered by sqlglot. [demo](https://sqlforge.dengshu.ovh/)

**[xlsx2spark](https://github.com/dengshu2/xlsx2spark)** — Excel / CSV → Spark SQL `INSERT` and `CREATE TABLE`, entirely in the browser. [demo](https://xlsx2spark.dengshu.ovh)

**[Astrolabe](https://github.com/dengshu2/Astrolabe)** — Enter a GitHub username to see the languages, timeline and health of everything they starred. [demo](https://astrolabe.dengshu.ovh/)

**[WordCore](https://github.com/dengshu2/wordcore)** — Core English vocabulary practice: study cards, native pronunciation, write a sentence and get AI feedback.
